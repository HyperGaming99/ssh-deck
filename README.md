# SSH Deck

An SSH client for Linux, Windows and macOS: terminal tabs with themes, SFTP (drag & drop, server to server), keychain, known hosts, port forwarding, host import, end-to-end encrypted cloud sync and optional Tor routing. 16 languages.

```bash
npm install
npm start      # builds the UI and starts the app
npm test
```

Updates: Settings → Updates checks the latest GitHub release of this repository (`updates.repo` in `package.json`) and installs it for source installs.
